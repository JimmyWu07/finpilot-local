## 情感打分算法

### 基础公式

```python
def calculate_sentiment_score(text, pos_words, neg_words):
    """
    计算情感得分
    返回值域: [-100, 100]
    """
    pos_count = sum(1 for w in pos_words if w in text)
    neg_count = sum(1 for w in neg_words if w in text)
    total_words = max(len(text), 1)
    
    # 负面词权重1.2倍(负面信息影响更大)
    raw_score = (pos_count - neg_count * 1.2) / (total_words ** 0.3) * 100
    
    # 限制在[-100, 100]区间
    return max(-100, min(100, raw_score))
```

### 情感分类阈值

| 得分区间 | 情感倾向 | 标签 |
|---------|---------|------|
| > 20 | positive | 正面 |
| -20 ~ 20 | neutral | 中性 |
| < -20 | negative | 负面 |

### 特殊语境处理

| 语境 | 处理方式 |
|------|---------|
| "利空出尽" | 反转为正面(+30) |
| "否极泰来" | 反转为正面(+30) |
| "不及预期" | 负面(-40) |
| "符合预期" | 中性(0) |
| "超预期" | 正面(+40) |

## 置信度计算规则

### 置信度公式

```python
def calculate_confidence(pos_count, neg_count):
    """
    计算置信度
    基于命中词数量判断词典匹配的可靠程度
    """
    total_hits = pos_count + neg_count
    confidence = min(1.0, total_hits / 5)
    return confidence
```

### 置信度阈值

| 置信度 | 判定 | 处理方式 |
|--------|------|---------|
| >= 0.7 | high_confidence | 直接使用机器打分 |
| < 0.7 | low_confidence | 需送入LLM二次校正 |

## 权重配置

### 三维度权重

| 维度 | 权重 | 说明 |
|------|------|------|
| 宏观政策 | 0.40 | 政策对行业影响最大 |
| 行业动态 | 0.35 | 行业景气度直接影响 |
| 个股新闻 | 0.25 | 公司层面信息 |

### 加权综合分计算

```python
def calculate_composite_score(policy_score, industry_score, stock_score):
    """
    计算三维度加权综合分
    """
    return (
        policy_score * 0.40 +
        industry_score * 0.35 +
        stock_score * 0.25
    )
```

### 综合情感分类

| 综合分区间 | 整体情感 | 投资建议 |
|-----------|---------|---------|
| > 30 | 强烈正面 | 关注机会 |
| 10 ~ 30 | 偏正面 | 适度乐观 |
| -10 ~ 10 | 中性 | 观望为主 |
| -30 ~ -10 | 偏负面 | 谨慎对待 |
| < -30 | 强烈负面 | 规避风险 |

## 关键话题提取

### 话题聚类规则

1. 从新闻标题中提取高频词(>=2次出现)
2. 合并同义词(如"降息"/"降准" → "货币宽松")
3. 按出现频次排序，取Top 5作为key_topics

| 关键词组合 | 话题标签 |
|-----------|---------|
| 降息+降准+流动性 | "货币宽松预期" |
