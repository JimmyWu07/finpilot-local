## 核心金融知识点

### 财务分析知识点

#### 1. 杜邦分析法

**定义**: 将ROE分解为多个驱动因素的乘积

**公式**:
```
ROE = 净利率 x 总资产周转率 x 权益乘数
    = (净利润/营收) x (营收/总资产) x (总资产/净资产)
```

**教学要点**:
- 净利率反映盈利能力
- 总资产周转率反映运营效率
- 权益乘数反映财务杠杆
- 三者共同决定股东回报

**适用场景**: 分析ROE变化的根本原因

---

#### 2. 自由现金流(FCF)

**定义**: 企业在满足再投资需求后可自由支配的现金流

**公式**:
```
FCF = 经营性现金流 - 资本支出
    = EBIT x (1-税率) + 折旧摊销 - 营运资本变动 - 资本支出
```

**教学要点**:
- FCF比净利润更难操纵
- 持续正FCF是企业健康的标志
- FCF是估值的基础(DCF模型)

**适用场景**: 评估企业真实盈利质量

---

#### 3. 商誉减值

**定义**: 并购溢价(商誉)因被收购方价值下降而需计提的损失

**触发条件**:
- 被收购方业绩不及预期
- 行业环境发生重大不利变化
- 技术变革导致核心竞争力下降

**教学要点**:
- 商誉减值直接冲减当期利润
- 大额商誉是潜在风险点
- 并购时需关注溢价合理性

**适用场景**: 评估并购风险、判断资产质量

---

### 估值分析知识点

#### 4. PE估值法

**定义**: 市盈率 = 股价 / 每股收益

**变体**:
| 类型 | 说明 | 适用场景 |
|------|------|---------|
| 静态PE | 基于上一年EPS | 稳定行业 |
| 动态PE(TTM) | 基于最近12个月EPS | 通用 |
| 预测PE | 基于未来预测EPS | 成长股 |

**教学要点**:
- PE需与同行业对比才有意义
- 高PE可能反映高成长预期
- 周期股在盈利高点PE反而低

---

#### 5. PB估值法

**定义**: 市净率 = 股价 / 每股净资产

**适用场景**:
- 银行、保险等重资产行业
- 周期股底部判断
- 破净股筛选

**教学要点**:
- PB<1可能意味着低估或资产质量差
- 轻资产公司PB参考价值有限
- 需结合ROE分析(PB/ROE关系)

---

#### 6. DCF估值法

**定义**: 现金流折现模型，将未来自由现金流折现到当前

**公式**:
```
企业价值 = SUM(FCF_t / (1+WACC)^t) + 终值 / (1+WACC)^n
```

**教学要点**:
- WACC: 加权平均资本成本
- 终值: 预测期后的永续价值
- 对假设敏感度高，需做敏感性分析

**适用场景**: 稳定现金流企业的内在价值评估

---

### 技术分析知识点

#### 7. 移动平均线(MA)

**定义**: 一定时期内收盘价的平均值连线

**常用周期**:
| 均线 | 用途 |
|------|------|
| MA5/MA10 | 短期趋势 |
| MA20 | 中期趋势(月线) |
| MA60 | 中长期趋势(季线) |
| MA250 | 长期趋势(年线) |

**交易信号**:
- 金叉: 短期均线上穿长期均线 → 看涨
- 死叉: 短期均线下穿长期均线 → 看跌
- 多头排列: MA5>MA10>MA20>MA60 → 强势

---

#### 8. MACD指标

**定义**: 指数平滑异同移动平均线

**组成**:
- DIF(快线): 12日EMA - 26日EMA
- DEA(慢线): DIF的9日EMA
- MACD柱: (DIF-DEA) x 2

**交易信号**:
- DIF上穿DEA: 金叉 → 买入信号
- DIF下穿DEA: 死叉 → 卖出信号
- 柱状线由负转正: 趋势转强

---

### 风险管理知识点

#### 9. VaR(风险价值)

**定义**: 在给定置信水平下，一定时期内的最大预期损失

**示例**: "95%置信度下，1日VaR为100万"意味着有95%的把握，单日损失不超过100万

**计算方法**:
- 历史模拟法
- 方差-协方差法
- 蒙特卡洛模拟

---

#### 10. 夏普比率

**定义**: 衡量单位风险所获得的超额回报

**公式**:
```
夏普比率 = (投资回报率 - 无风险利率) / 回报率标准差
```

**教学要点**:
- 夏普比率越高越好
- >1为优秀，>2为卓越
- 需与同类基金/策略对比

## 投资分析方法论

### 自上而下分析法(Top-Down)

```
宏观经济 → 行业选择 → 个股精选
   ↓           ↓           ↓
 GDP/ CPI    景气度      财务分析
 货币政策    竞争格局    估值水平
 财政政策    政策导向    管理层
```

**适用场景**: 大类资产配置、行业轮动

### 自下而上分析法(Bottom-Up)

```
公司基本面 → 竞争优势 → 估值判断
    ↓           ↓           ↓
  财务分析   护城河      安全边际
  管理层     成长性      买入时机
  治理结构   可持续性    目标价格
```

**适用场景**: 价值投资、长期持有

### 事件驱动分析法

```
事件识别 → 影响评估 → 交易策略
    ↓           ↓           ↓
  政策变化   受益/受损    做多/做空
  并购重组   短期/长期    仓位管理
  业绩公告   幅度判断    止盈止损
```

**适用场景**: 短期交易、套利策略

## 经典案例解析

### 案例1: 贵州茅台(600519) - 价值投资典范

**分析框架**:
1. **行业分析**: 白酒行业高壁垒、强品牌、消费升级
2. **竞争格局**: 高端白酒龙头，定价权强
3. **财务特征**: 毛利率>90%，ROE>30%，现金流充沛
4. **估值逻辑**: 确定性溢价，DCF估值

**教学要点**:
- 护城河理论的实际应用
- 高ROE的可持续性分析
- 消费品估值方法

---

### 案例2: 平安银行(000001) - 银行业分析

**分析框架**:
1. **行业特征**: 高杠杆经营、强监管、周期性
2. **核心指标**: 净息差(NIM)、不良率、拨备覆盖率
3. **转型分析**: 零售转型成效
4. **估值方法**: PB估值为主

**教学要点**:
- 银行业特殊财务指标
- 资产质量分析(不良贷款)
- 利率市场化影响

---

### 案例3: 宁德时代(300750) - 成长股分析

**分析框架**:
1. **行业趋势**: 新能源车渗透率、动力电池需求
2. **竞争地位**: 全球动力电池龙头
3. **成长性**: 营收/利润增速、产能扩张
4. **估值挑战**: 高PE的合理性判断

**教学要点**:
- 成长股估值方法(PEG)
- 技术路线风险分析
- 高估值的风险因素
