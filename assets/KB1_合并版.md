# 第一部分：A股预测模型
| 字段 | 内容 |
|---|---|
| doc_id | KB1_a_share_prediction_model_v1 |
| 版本号 | v1.0 |
| 生成日期 | 2026-08-01 |
| 规则截止日 | 2026-08-01 |
| 适用市场 | 上海证券交易所 / 深圳证券交易所 / 北京证券交易所 |
| 适用证券类型 | 普通 A 股；ST、北交所、科创板、创业板需单独标注交易规则差异 |
| 标签 | 多因子模型, A股, 回测, 教学, 趋势预测 |
本文件用于描述 A 股趋势预测的输入、特征、训练、回测、输出和限制，仅做教学实训和辅助分析，不构成投资建议。
## 模型定位
目标是预测 1 个月、3-6 个月的趋势方向和不确定性区间，不承诺收益率或预测准确率，不提供具体买卖建议。模型只默认适用于 A 股，不自动外推到基金、债券、期货、期权、港股或美股。
## 输入因子
| 因子组 | 字段示例 | 来源 |
|---|---|---|
| 行情因子 | 近30/60/120日收益率、成交量、换手率、波动率、最大回撤 | 市场行情 |
| 技术因子 | MA、RSI、MACD、布林带、量价背离 | 技术模块 |
| 财务因子 | 12项核心财务指标 | 财务指标模块 |
| 舆情因子 | 综合情绪值、新闻数量、来源可信度 | 舆情分析模块 |
| 风险因子 | 综合风险得分、重大风险标签 | 风险评分模块 |
| 行业因子 | 申万/GICS行业、行业景气度、估值分位 | 行业与估值模块 |
## 因子工程
| 步骤 | 说明 |
|---|---|
| 缺失值处理 | 删除、行业中位数填充、前向填充或缺失标记，按字段性质选择 |
| 极值缩尾 | 使用 winsorize，避免异常点主导模型 |
| 标准化 | 使用 z-score，便于不同量纲比较 |
| 中性化 | 对行业、市值、风格进行中性化，降低结构偏差 |
| 财务滞后 | 财务数据按公告日滞后可得，禁止使用未来数据 |
| 标签定义 | 未来20个交易日收益率、未来60/120个交易日收益率，或相对行业超额收益 |
## 标签与口径
| 标签 | 定义 | 默认用途 |
|---|---|---|
| 20日收益 | 未来20个交易日区间收益 | 短期方向 |
| 60日收益 | 未来60个交易日区间收益 | 中期趋势 |
| 120日收益 | 未来120个交易日区间收益 | 中期确认 |
| 行业超额收益 | 个股收益减行业基准收益 | 过滤行业共振 |
## 模型方法
基础模型优先使用多因子线性回归或逻辑回归，便于解释方向和因子贡献。若扩展到随机森林、XGBoost 等非线性模型，需明确可解释性降低，且不能省略样本外验证。输出应至少包含趋势方向、预测分数、置信区间、关键贡献因子和风险提示。
| 方法 | 优点 | 局限 |
|---|---|---|
| 线性回归 | 解释性强，适合教学 | 难刻画非线性 |
| 逻辑回归 | 适合涨跌分类 | 对阈值敏感 |
| 随机森林 | 抗噪较强 | 解释性下降 |
| XGBoost | 拟合能力强 | 更易过拟合 |
## 交易规则差异
| 证券类型 | 说明 |
|---|---|
| 普通 A 股 | 默认适用 |
| ST | 涨跌幅、风险提示和流动性需单独处理 |
| 北交所 | 流动性和波动特征不同，需单列样本 |
| 科创板 | 高波动、研发与事件驱动更强 |
| 创业板 | 风格切换明显，需强化行业和市值中性化 |
## 回测与验证
至少使用近3-5年历史数据，若样本不足需标注。验证方式优先滚动窗口或 walk-forward，不得只展示训练集表现。核心报告项包括命中率、IC、Rank IC、最大回撤、换手率、交易成本后收益，以及样本外测试结果。
| 指标 | 说明 |
|---|---|
| 命中率 | 方向判断正确比例 |
| IC | 因子值与未来收益相关性 |
| Rank IC | 排名相关性 |
| 最大回撤 | 最差累计回撤 |
| 换手率 | 持仓变动频率 |
| 交易成本后收益 | 扣除手续费和冲击成本后的结果 |
## 关键风险
| 风险 | 说明 |
|---|---|
| 数据泄漏 | 不能使用未来可得信息 |
| 幸存者偏差 | 不能只保留存活样本 |
| 前复权/后复权 | 必须统一口径并写明用途 |
| 停牌与 ST | 需单独处理可交易性 |
| 退市 | 需保留退市样本 |
| 交易成本 | 手续费、滑点、冲击成本必须入模或回测扣除 |
## 压力测试
| 场景 | 检查重点 |
|---|---|
| 市场急跌 | 风险因子是否失真、回撤是否放大 |
| 行业监管突变 | 行业因子是否失效 |
| 财报不及预期 | 财务滞后数据是否误导 |
| 流动性下降 | 换手与滑点是否恶化 |
| 舆情负面爆发 | 情绪因子是否迅速转负 |

## 模型限制说明
该模型只适合 A 股教学和辅助分析，不默认适用于其他资产类别；预测的是概率与方向，不是确定结果。模型效果会受样本质量、制度变化、复权口径、交易成本、滑点、停牌和退市样本影响，任何"高胜率"表述都应视为待核验。

| 字段 | 内容 |

| doc_id | KB1_risk_models_v1 |
| 版本号 | v1.0 |
| 生成日期 | 2026-08-01 |
| 规则截止日 | 2026-08-01 |
| 适用市场 | A/HK/US |
| 适用行业 | 制造、消费、银行、保险、地产、基建、公用、科技/互联网、医药研发 |
| 风险范围 | 财务、行业、舆情、跨境、综合评分 |
| 维护建议 | 季度更新；遇审计/退市/监管变化立即核验 |
| 标签 | 风控, IF-THEN, 审计, 违约, 跨境, 评分 |
本文件定义风险触发条件、行业例外、跨境风险和综合评分，仅用于教学与辅助分析，不构成投资建议。  
硬触发：审计非标、连续亏损、违约等；软信号：高负债、毛利下滑、商誉偏高等。
## 通用财务风险
| rule_id | 风险名称 | 输入字段/单位 | IF-THEN 触发逻辑 | 严重性 | 观察周期 | 置信度 | 适用行业 | 排除行业 | 缺失值 | 建议输出 |
|---|---|---|---|---|---|---|---|---|---|---|
| R001 | 高负债 | 资产负债率/% | 资产负债率>70% THEN 触发 | warning | 年度/TTM | high | 全行业 | 银行/保险/地产/基建/公用 | 缺失则核验 | 负债偏高，复核债务期限与现金流 |
| R002 | 流动性不足 | 流动比率/倍 | 流动比率<1.5 THEN 触发 | warning | 季度/TTM | high | 制造/消费/科技/医药 | 银行/保险 | 缺失则不判定 | 短债覆盖偏弱，关注回款与融资 |
| R003 | 商誉偏高 | 商誉/净资产/% | 商誉/净资产>30% THEN 触发 | warning | 年度 | medium | 并购频繁行业 | 无 | 净资产≤0则人工核验 | 商誉压力较大，关注减值测试 |
| R004 | 连续亏损 | 归母净利润/元 | 连续2个完整财年<0 THEN 触发 | danger | 连续2年 | high | 全行业 | 无 | 任一年缺失则核验 | 已连续亏损，优先核查经营与退市约束 |
| R005 | 毛利下滑 | 毛利率/% | 同比下降>20pct或相对下降>20% THEN 触发 | warning | 季度/年度 | medium | 制造/消费/科技/医药 | 银行/保险/公用 | 对比期缺失则不判定 | 毛利承压，区分价格、成本、结构与一次性因素 |
| R006 | 利润现金流背离 | 净利润、经营现金流/元 | 净利润>0且经营现金流连续2年<0 THEN 触发 | danger | 连续2年 | high | 全行业 | 银行/保险可改用同类口径 | 现金流缺失则核验 | 盈利兑现弱，核查回款、存货、应收 |
| R007 | 审计异常 | 审计意见/类别 | 非标/保留/无法表示/否定 THEN 触发 | danger | 年度 | high | 全行业 | 无 | 缺失即核验 | 审计异常，需人工复核财报真实性 |
```text
R001 IF 资产负债率 > 70% THEN 高负债
R002 IF 流动比率 < 1.5 THEN 流动性不足
R003 IF 商誉/净资产 > 30% THEN 商誉偏高
R004 IF 连续2个完整财年归母净利润 < 0 THEN 连续亏损
R005 IF 毛利率同比下降 > 20个百分点 OR 相对下降 > 20% THEN 毛利下滑
R006 IF 净利润 > 0 AND 经营现金流连续2年 < 0 THEN 利润现金流背离
R007 IF 审计意见 = 非标/保留/无法表示/否定 THEN 审计异常
```
## 行业特殊规则
| 行业 | 不适用通用规则时的替代指标 |

| 科技/互联网 | 研发资本化、用户增长、商誉减值、监管处罚 |
| 制造 | 存货周转、产能利用率、应收周转、原材料价格波动 |
| 医药研发 | 管线失败、集采降价、专利到期、临床审批风险 |
## 跨境风险
| 风险 | 触发/说明 |
|---|---|
| 汇率风险 | 非本币收入/资产/负债占比>30%时提示，需写明币种与换算日 |
| 地缘政治 | 制裁、出口管制、实体清单、市场准入限制 |
| 监管差异 | 准则、披露、投资者保护、税务规则不同 |

## 风险评分
单项严重性：danger=3，warning=2，info=1。综合风险分=财务50%+行业30%+舆情20%；各维度先归一化到0-100，缺失维度不按0分，改为标记缺失、已知维度重归一化并降低置信度。映射：0-29低风险，30-59中风险，60-100高风险；出现审计异常、连续亏损、债务违约等重大事件，可一票提升至高风险，并注明原因。  
建议：80分以上不单独细分，直接视为高风险区间中的最优先复核对象。
## 来源与口径说明
阈值均为内部经验阈值，不等同于监管标准或投资建议；审计、违约、退市、财务口径以公开财报、公告和监管披露为准。无法核验的来源、页码、URL、条文写"待补充/需人工核验"。

## 文档定位
本文件用于解释核心财务指标、公式、阈值和适用边界，仅用于教学与辅助分析，不构成投资建议。以下阈值均为内部经验阈值，非监管标准或投资建议。
## 综合评分
综合得分 = 财务维度50% + 行业维度30% + 舆情维度20%。各维度均先映射到0-100分；缺失维度不按0分，需标记缺失、对已知维度重归一化，并降低置信度。等级映射：80-100优质，60-79良好，40-59一般，20-39较差，0-19危险；80分归入"优质"。
### 指标：资产负债率（debt_ratio）
| 项 | 内容 |
|---|---|
| 定义 | 总负债占总资产比例 |
| 公式 | $总负债/总资产$ |
| 口径 | 单位：%；总额口径；分母为0/负数/缺失则标记需人工核验 |
| 方向 | 越低越好 |
| 阈值 | ≤30优, ≤50健, ≤70预警, >70危 |
| 差异 | 银行/保险/地产/基建/公用事业可显著高于消费制造；互联网平台与生物医药研发型企业更看现金与融资弹性 |
| 误读 | 高负债不必然差，低负债也不必然优 |
| 缺失处理 | 资产或负债缺失时不补0 |
### 指标：流动比率（current_ratio）
| 项 | 内容 |
|---|---|
| 定义 | 流动资产覆盖流动负债能力 |
| 公式 | $流动资产/流动负债$ |
| 口径 | 单位：倍；优先合并报表；分母≤0则需核验 |
| 方向 | 越高越好 |
| 阈值 | ≥2.5优, ≥1.5健, ≥1.0预警, <1.0危 |
| 差异 | 银行/保险不宜直接套用；地产、基建看回款节奏 |
| 误读 | 高流动比率可能来自存货或应收膨胀 |
### 指标：速动比率（quick_ratio）
| 项 | 内容 |
|---|---|
| 定义 | 更严格的短债覆盖 |
| 公式 | $(流动资产-存货-预付款项)/流动负债$ |
| 口径 | 单位：倍；流动负债为0时需核验 |
| 方向 | 越高越好 |
| 阈值 | ≥1.5优, ≥0.8健, ≥0.5预警, <0.5危 |
| 差异 | 制造、消费、地产更常用；银行/保险通常不作为主指标 |
| 误读 | 忽略预付和应收质量会高估偿债能力 |
### 指标：毛利率（gross_margin）
| 项 | 内容 |
|---|---|
| 定义 | 销售扣除直接成本后的盈利能力 |
| 公式 | $(营业收入-营业成本)/营业收入$ |
| 口径 | 单位：%；可用合并报表；收入为0则需核验 |
| 方向 | 越高越好 |
| 阈值 | ≥60优, ≥30健, ≥15预警, <15危 |
| 差异 | 消费、软件、白酒通常较高；银行/保险/公用事业口径不适用或需专门调整 |
| 误读 | 毛利率高不等于净利率高 |
### 指标：净利率（net_margin）
| 项 | 内容 |
|---|---|
| 定义 | 最终留存利润占收入比例 |
| 公式 | $归母净利润/营业收入$ |
| 口径 | 单位：%；优先归母口径；收入为0或负数需核验 |
| 方向 | 越高越好 |
| 阈值 | ≥20优, ≥8健, ≥3预警, <3危 |
| 差异 | 银行/保险/地产/基建波动受周期和会计处理影响大 |
| 误读 | 一次性收益会抬高净利率 |
### 指标：净资产收益率（ROE）
| 项 | 内容 |
|---|---|
| 定义 | 股东资本回报 |
| 公式 | $归母净利润/平均归母净资产$ |
| 口径 | 单位：%；优先平均净资产；仅有期末值时降级为期末净资产并标注 |
| 方向 | 越高越好 |
| 阈值 | ≥20优, ≥8健, ≥3预警, <3危 |
| 差异 | 银行/保险重点看资本效率；高杠杆行业ROE需联看风险 |
| 误读 | 期末净资产过小会虚高 |
### 指标：总资产收益率（ROA）
| 项 | 内容 |
|---|---|
| 定义 | 全部资产创造利润能力 |
| 公式 | $净利润/平均总资产$ |
| 口径 | 单位：%；优先平均总资产；仅有期末值时降级 |
| 方向 | 越高越好 |
| 阈值 | ≥10优, ≥4健, ≥1预警, <1危 |
| 差异 | 银行、保险、基建更有比较意义；重资产企业通常偏低 |
### 指标：营收同比增长率（revenue_yoy）
| 项 | 内容 |
|---|---|
| 定义 | 收入较去年同期变化 |
| 公式 | $(本期-对比期)/对比期$ |
| 口径 | 同比；年度默认同比，季度可同时写同比/环比，月度可写月环比 |
| 阈值 | ≥30优, ≥5健, ≥0预警, <0危 |
| 差异 | 季节性强行业需同时看环比 |
| 误读 | 基数低会放大增速 |
### 指标：净利同比增长率（profit_yoy）
| 项 | 内容 |
|---|---|
| 定义 | 净利润较去年同期变化 |
| 公式 | $(本期-对比期)/对比期$ |
| 口径 | 同比；分母为0、负数、缺失需标记 |
| 阈值 | ≥30优, ≥5健, ≥0预警, <0危 |
| 差异 | 生物医药研发型企业、互联网平台波动较大 |
| 误读 | 低基数和一次性收益会扭曲结论 |
### 指标：商誉/净资产比率（goodwill_ratio）
| 项 | 内容 |
|---|---|
| 定义 | 商誉相对净资产的压力 |
| 公式 | $商誉/净资产$ |
| 口径 | 单位：%；净资产≤0需人工核验 |
| 方向 | 越低越好 |
| 阈值 | ≤5优, ≤15健, ≤30预警, >30危 |
| 差异 | 并购频繁行业更重要 |
| 误读 | 商誉低不代表没有减值风险 |
### 指标：总资产周转率（asset_turnover）
| 项 | 内容 |
|---|---|
| 定义 | 资产使用效率 |
| 公式 | $营业收入/平均总资产$ |
| 口径 | 单位：次；优先平均总资产；只有期末值时降级 |
| 方向 | 越高越好 |
| 阈值 | ≥0.8优, ≥0.5健, ≥0.3预警, <0.3危 |
| 差异 | 银行、保险、地产、基建、公用事业通常低于轻资产行业 |
### 指标：存货周转率（inventory_turnover）
| 项 | 内容 |
|---|---|
| 定义 | 存货消化速度 |
| 公式 | $营业成本/平均存货$ |
| 口径 | 单位：次；平均存货优先，期末值仅作降级 |
| 方向 | 越高越好 |
| 阈值 | ≥5优, ≥2健, ≥1预警, <1危 |
| 差异 | 普通制造、消费最常用；银行/保险通常不适用 |
| 误读 | 低库存不一定好，可能缺货或供应受限 |
## 来源与口径说明
阈值为内部经验阈值，不等同于监管标准或投资建议；公式口径参考公开财报、通用会计报表定义与常见财务分析方法。具体公司还需结合行业、会计准则、合并范围、币种、报告期与一次性事项核验。
## 同比/环比口径说明
同比默认年度/季度经营数据使用；季度数据可同时写同比和环比；月度数据可写月环比。增长率统一写作$(本期-对比期)/对比期$，并明确本期、对比期与季节性影响。
